# Camadas animáveis v1

Esta pasta recebe somente os assets finais aprovados. O manifesto descreve nomes, ordem de pintura e requisitos, mas não considera uma camada pronta até que o arquivo exista, seja auditado e tenha pivôs revisados.

Use PNG lossless com transparência para as camadas de produção. SVG é permitido apenas para máscaras de pupila. WebP pode ser produzido depois como otimização de entrega, nunca como único arquivo-fonte.
