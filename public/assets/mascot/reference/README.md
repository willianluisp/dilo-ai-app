# Referências imutáveis do mascote

Esta pasta guarda apenas referências visuais. Elas não são usadas diretamente pelo renderer de camadas.

- `dilo-mascote-original-210x194.png`: cópia preservada do PNG que já está em uso no login. Ela não deve ser recortada, comprimida, editada ou sobrescrita.
- `dilo-mascote-master-reference.png`: destino reservado para a nova imagem em alta resolução fornecida pelo time. O arquivo ainda não foi recebido e, portanto, não existe nesta etapa.

Ao adicionar a nova referência, preserve o arquivo original, use PNG com alpha quando disponível e registre resolução, perfil de cor e origem no PR ou na documentação do asset.
